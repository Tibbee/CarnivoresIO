CarnivoresIO 2.4.0 — Release Notes
==================================

Compact summary of what changed since 2.3.1. The full changelog lives at:
https://github.com/Tibbee/CarnivoresIO/blob/main/CHANGELOG.md

New
---
- Audio: an AudioManager owns all runtime sound playback; focused
  playback is now strictly exclusive (preview / NLA tweak / timeline);
  per-action and scene volume controls with live updates; legacy
  action["carnivores_sound"] links are migrated to pointers on load.
- Rig reconstruction Phases 0-7: lossless CAR owner handling, pure
  geometry analysis, anatomy-aware topology (bilateral pairing,
  central backbone, mirrored components), improved weights,
  transactional armature lifecycle, safe analyze->preview->apply
  proposal workflow, and round-trip export reconciliation.
- Model health preflight wired into all export dialogs: geometry,
  flags, UVs, rigs, names, quantization, audio, and C2 MEE checks;
  errors block export by default.

Fixed
-----
- CAR export no longer silently drops animations: failed bakes abort
  with a report error, and diagnostics (static animations, missing
  sound data, >64 animations, cross-reference truncation) now appear
  in the operation report instead of the console.
- All exporters (.3df, .car, .3dn, .vtl) write atomically: an
  interrupted export can no longer destroy the previous file.
- Imports and exports are undoable (Ctrl+Z); a failed import rolls
  back everything it created instead of leaving orphans.
- Re-Sync Timing preserves the imported shape-key mode; re-syncing
  absolute shape keys no longer exports a static rest pose.
- The shape-key fast path is only used for position-preserving
  modifiers; visible Mirror/Subdivision/Decimate/... modifiers force
  the slower, correct evaluated bake in CAR and VTL export.
- Untextured models (texture_size = 0) import cleanly with a warning.
- Serialized names share one sanitization rule across all formats
  (split at first NUL, byte-aware truncation).
- The 3DN exporter refuses bone counts beyond the signed 16-bit
  parent-index range instead of silently wrapping.
- Sound export mapping is keyed by sound datablock identity.

Changed
-------
- Importing no longer replaces the scene's world: the CustomWorld
  lighting setup is an explicit opt-in option in the import dialog
  (off by default; enable it for the old behavior).
- CAR exports that previously "succeeded" while dropping animations
  will now abort; fix the reported animation and re-export.
- The ARGB1555 alpha bit is still forced to 0 on export - this is
  deliberate (engine-undefined behavior with alpha = 1), see
  doc/reference.md in the repository.

Performance
-----------
- Faster CAR/VTL round trips: direct shape-key sampling, NumPy-
  vectorized baking, reduced import/export overhead; optional
  structured performance report in addon preferences.

UI
--
- Redesigned file-dialog option panels, clearer tooltips, post-import
  focus/selection/framing options, model health panel, structured
  operation reports, modern face-flag editing with preserved
  filtered selections.

Testing
-------
- Automated suite expanded to 118 tests across 11 files.
